# AEGIS — Open-Source License Register & Dependency Audit

## 1. Governance Policy
AEGIS enforces strict compliance with open-source software licenses to protect proprietary commercial intellectual property. Permissive open-source licenses (Apache-2.0, MIT, BSD-3-Clause) are approved. Viral copyleft licenses (GPL, AGPL) are prohibited from the codebase.

## 3. Commercial IP Segregation
All core AEGIS domain models, policy engine rules, context completeness algorithms, and attack path tracing engines are original proprietary works protected under Apache-2.0 open-source licensing for the hackathon baseline with full commercial reservation for enterprise extensions.
